# Clippy Training Library

This is a flat-file GitHub Pages test site. All files are in the repository root so they can be selected and uploaded together in the browser.

## Publish
1. Upload every file from this folder to the root of the repository.
2. Commit the changes to `main`.
3. In Settings -> Pages, publish from branch `main`, folder `/(root)`.

Important: keep `index.html`, `app.js`, `style.css`, `index.json`, and all `.md` files in the repository root. Do not upload the ZIP itself.

The site is a static catalog. To add or replace a lesson, upload its `.md` file and edit `index.json` to add/update the entry. The Clippy app must use the same root `index.json` and lesson paths.
